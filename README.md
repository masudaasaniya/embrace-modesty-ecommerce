# Embrace Modesty – E-commerce Website

A PHP and MySQL e-commerce website for modest fashion, including abayas, hijabs, dresses, and accessories.

## Features

- User registration and login
- Product browsing and categories
- Shopping cart and wishlist
- Order placement and order history
- Admin panel for managing products and orders
- Coupon and banner management
- Password recovery and email functionality
- PDF invoice generation

## Technologies Used

- PHP
- MySQL
- HTML5 and CSS3
- JavaScript
- Bootstrap
- PHPMailer
- FPDF
- WAMP Server

## Requirements

- WAMP Server or another PHP/MySQL environment
- A web browser
- MySQL database

## Local Setup

1. Copy the project folder into your web server's document root.
2. Create a MySQL database for the project.
3. Configure your local database connection in `connect.php` or `db.php`.
4. Import the database schema and required tables into your database.
5. Configure email settings locally if you want to use email features.
6. Start Apache and MySQL.
7. Open `http://localhost/php-ecom/` in your browser.

## Security Notes

- Keep database credentials and email passwords private.
- Do not use default administrator credentials on a public or production website.
- Configure a unique administrator password before using the application.
- Do not commit private configuration files or customer data.

## Project Purpose

This project was developed to practice PHP, MySQL, CRUD operations, authentication, session handling, and e-commerce website development.
